# CUNY Beyond - User Stories

## Prospective or high-school student

1. As a prospective student, I want onboarding to feel like a simple conversation so that I am not overwhelmed by an institutional form.
2. As a high-school student, I want to begin with a career goal so that majors are explained in terms I understand.
3. As a visitor, I want optional quick-choice tags and free text so that I can answer efficiently without losing flexibility.
4. As a visitor who does not know an exact job title, I want to browse and filter reviewed careers so that I can discover supported options.
5. As a prospective student, I want each recommendation to explain why it appeared and link to an official source so that I can verify it.

## Working adult or returning learner

6. As a working adult, I want to identify skills I already use so that recommendations reflect more than a job-title keyword.
7. As a returning learner, I want the draft to resume on the same device for a limited time so that an interruption does not force me to restart.
8. As an adult with prior training, I want possible CPL paths and a document checklist so that I can prepare for an official evaluation.
9. As a privacy-conscious visitor, I want to explore without an account or personal identifiers so that I can decide whether to proceed safely.

## Transfer student

10. As a transfer student, I want to disclose prior college credit without uploading a transcript during exploration so that I can prepare before formal evaluation.
11. As a transfer student, I want reviewed transfer options separated from unverified possibilities so that I understand what still needs advisor confirmation.
12. As a transfer student, I want to open the interactive degree planner for a recommended program so that I can examine requirements and equivalencies.

## Current student considering a major change

13. As a current student, I want a direct handoff to the authenticated major-change workflow so that completed courses can be reused.
14. As a student changing majors, I want recommended programs to open with the correct campus, program, and catalog context so that I do not select the wrong curriculum.
15. As a current student, I want remaining requirements and schedule-search questions prepared for an advisor so that the meeting focuses on decisions.

## Student seeking a licensed or advanced profession

16. As a student interested in counseling, psychology, law, accounting, or health administration, I want clear education and credential warnings so that an associate degree is not presented as full professional eligibility.
17. As a nursing student, I want the recommendation to distinguish the degree pathway from licensure requirements so that expectations are accurate.

## Academic or career advisor

18. As an advisor, I want a concise summary of the student's goal, skills, recommendations, CPL questions, and sources so that I can prepare for the conversation.
19. As an advisor, I want unsupported goals to produce no match instead of a guess so that students are not misdirected.
20. As an advisor, I want every career-program relationship to have an explanation, source, and review date so that guidance is auditable.

## CPL or transfer evaluator

21. As a CPL evaluator, I want the tool to request documents rather than award estimated credit so that institutional evaluation remains authoritative.
22. As a transfer evaluator, I want the summary to distinguish reviewed options and equivalencies from items requiring review so that students understand uncertainty.

## Content administrator

23. As an administrator, I want career and program mappings governed separately from student responses so that content changes do not expose private drafts.
24. As an administrator, I want draft, approval, publication, archive, version, and rollback controls so that incorrect mappings can be prevented or reversed.
25. As an administrator, I want active careers to require populated curricula and official sources so that no empty major is recommended.

## Tester and maintainer

26. As a tester, I want reproducible career examples and page addresses so that I can verify the same outcome consistently.
27. As a keyboard user, I want every quick option and navigation control to be reachable without a mouse so that the onboarding is accessible.
28. As a mobile user, I want the chat, tags, and recommendation cards to fit a narrow screen so that exploration works on a phone.
29. As a maintainer, I want regression tests for aliases, sources, mappings, roles, and existing majors so that catalog expansion does not corrupt established behavior.
30. As a system administrator, I want public exploration separated from protected administration so that a tester or anonymous visitor cannot publish changes.
