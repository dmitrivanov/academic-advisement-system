## Status definitions

- **Complete**: an existing current-year curriculum was present and retained; the API returns a populated tree.
- **Partial**: the official directory program has multiple formal maps/tracks (or map-level areas of study) that the current schema cannot branch safely; one explicitly named representative map is loaded and all other variants are retained in source notes.
- **Needs Review**: the official two-year map is loaded and selectable, but one or more official footnotes depend on unsupported corequisites, term availability, permission, minimum-grade, repeatability, or a program-specific choice pool that requires advisor/maintainer confirmation.
- **Blocked**: the program remains represented, but a verified 2025–2026 tree was not substituted because doing so would require silently replacing a different catalog edition or extending the schema. Four associate curricula and the separately listed credentials have this status.
