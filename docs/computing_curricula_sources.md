# Computing curriculum standardization sources

The computing curricula use the same full curriculum schema and choice-group model
as the mathematics, science, and psychology programs.

## BMCC

- Computer Science: https://www.bmcc.cuny.edu/academics/departments/cis/computer-science/
- Computer Information Systems: https://www.bmcc.cuny.edu/academics/departments/cis/computer-information-systems-cis/
- Computer Network Technology: https://www.bmcc.cuny.edu/academics/departments/cis/computer-network-technology/

The published 2025-2026 requirements determine the Common Core restrictions,
required courses, and finite program-elective lists. CIS and CNT department-elective
pools use the published ACC/BUS/CIS/CSC/GIS/MMP subject rule and exclude CIS 100.
Computer Science retains its program selector course set while adding the published
CIS 317 option. The official degree map resolves an ambiguity in the summary table:
MAT 206 satisfies Common Core, while MAT 301 and MAT 302 remain a required curriculum
sequence. CSC 101 and CSC 111 remain in Flexible Core as the required Scientific
World courses. PHY 215 and SPE 100-or-SPE 102 retain their published Core placement.

## CCNY

- Computer Science curriculum sheet: https://www.ccny.cuny.edu/sites/default/files/2024-03/csc-curric-2023-2024--2023-07-06.pdf
- Grove liberal arts guidance: https://www.ccny.cuny.edu/engineering/pathways
- Fall 2026 approved Pathways courses: https://www.ccny.cuny.edu/sites/default/files/2026-03/CCNY%20Pathways%20Common%20Core%20Courses%20fall%202026.pdf

CCNY Flexible Core, technical-elective, and free-elective pools are institution-scoped
and never reuse BMCC Pathways memberships. The curriculum remains under its existing
2022-2023 program record; the current approved-course list supplies selector options.
